# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run sass       # Watch SCSS and compile to dist/css/main.css (Dart Sass)
npm run build:css  # One-shot CSS compile (deploy runs this first)
npm run photos     # Publish photos dropped into incoming/<Category>/ (see below)
npm run images     # Regenerate ALL thumbs + lightbox sizes and backfill w/h (one-off repair)
npm run deploy     # Build CSS, then deploy dist/ to GitHub Pages (custom domain 9smart.life)
```

**Adding photos:** drop edited exports into `incoming/<Category>/` (filename becomes the caption: `winter-stroll-in-japan.jpg` → "Winter Stroll In Japan"), run `npm run photos`, preview, then `npm run deploy`. Never hand-edit `dist/gallery/images.json`.

For local development, use VS Code Live Server on port 5501 (configured in `.vscode/settings.json`).

## Architecture

Static **single-page** personal portfolio site (see `docs/adr/0001-single-page-architecture.md`). `dist/index.html` holds four scroll Sections — Home (Hero), About, Gallery, Contact — under a sticky anchor-link header. `about.html`, `gallery.html`, `contact.html`, and `projects.html` are redirect stubs preserving old URLs; don't delete them. No templating engine or JS framework — interactivity is vanilla JS.

The design is **mobile-first Minimal Dark** (see `CONTEXT.md`): base CSS targets phones, `tabletUp`/`desktopUp` mixins scale up. Dark is the default theme; a header toggle switches to light and persists via `localStorage` (applied pre-paint by an inline script in `index.html`'s head). Both palettes are CSS custom properties in `scss/_config.scss` — dark on `:root`, light under `[data-theme="light"]`. One muted-green accent, Inter from Google Fonts.

**Source vs. output split:**
- `scss/` — source stylesheets only; never edit `dist/css/main.css` directly
- `dist/` — all deployable output: HTML, compiled CSS, JS, and images

**SCSS structure:**
- `scss/_config.scss` — theme variables and the mobile-first breakpoint mixins
- `scss/_gallery.scss` — gallery grid, filter chips, and lightbox
- `scss/main.scss` — imports the above; header, hero, sections, footer (media queries are co-located with components, not in a separate file)

**JavaScript:**
- `dist/js/main.js` — footer copyright year
- `dist/js/gallery.js` — gallery grid, filters, lightbox (keyboard + swipe; opening pushes a history entry so the phone Back button closes it)

**Gallery images:**
- Metadata in `dist/gallery/images.json` (file, caption, category, w, h per image), written by `scripts/add-photos.js` — not by hand. Derivatives are generated by `scripts/images.js` (macOS `sips`)
- Grid renders in batches of 24 (IntersectionObserver) so manifest size doesn't matter; see `docs/adr/0002-phased-gallery-scaling.md` for the scaling plan (bytes move to object storage at ~2k images)
- Grid uses `dist/gallery/thumbs/` (480px **wide**) and `thumbs/960/` (960px wide) via `srcset`, so portraits stay sharp on high-DPR phones; the lightbox shows the thumb, then swaps in `large/1600/` or `large/3000/` (q90, via `srcset`) — sharp on any screen without downloading the multi-MB original. The untouched original in `dist/gallery/` is linked as "View original"

**Icons:** inline SVGs in the HTML (no icon-font dependency).

## Deployment

`npm run deploy` runs `gh-pages` to push `dist/` to the `gh-pages` branch. Only `dist/` is deployed — source files stay on `master`.
